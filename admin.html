    La página

    Contenido del sitio

    Cambia los textos de la portada, apaga las secciones que no quieras mostrar y decide qué productos pasan en la imagen del titular y a qué velocidad.

    Carrusel del titular

    Más bajo = más rápido. El mínimo son 1,2 s para que se vea bien.

    Productos que sí pasan

    Si destapas los once, la portada muestra los once. Si dejas el carrusel apagado, vuelve la foto fija de las manos tejiendo.

    Secciones visibles

    Desmarca lo que quieras esconder por un tiempo. El titular y los productos no se pueden apagar porque son el corazón de la tienda.

    Automático

    Base de datos en la nube

    Todo lo del panel —clientas, pedidos, boletín, bitácora, creaciones, foro, catálogo y contenido— se guarda solo en la nube cada vez que algo cambia.

    Conexión con Supabase

    Solo local

    Solo en este navegador · pega tu URL y API key abajo.

    La key se guarda solo en este navegador y viaja directo a tu proyecto. Usa la clave pública (anon), nunca la service_role.

    Para crear la tabla: entra a Supabase → SQL Editor → pega el archivo supabase.sql que viene con la página → Run. Luego pega aquí la URL (Settings → Data API) y la anon key. Desde ese momento cada cuenta, pedido y suscripción se guarda solo, también desde el celular de tus clientas.
